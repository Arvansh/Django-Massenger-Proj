# Massenger - online Messaging Platform
## Massenger tools
### Technologias useed in development
#### Client-side of the interface
- HTML5
- CSS
- Js
#### Server Side of the Backend
- Django using python
### Features
- Login and creation of accounts
- Messages can be sent on other Users accounts
- Chat not accessible before login
- SQLite3 DataBase integration allows a small database enough for a class chat and a small group chat
